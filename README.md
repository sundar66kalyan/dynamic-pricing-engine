\# AI Dynamic Pricing Engine



This project builds a machine learning system that predicts optimal product prices based on market conditions.



\## Features

\- Demand forecasting

\- Competitor price analysis

\- Inventory-aware pricing

\- Machine learning models

\- Streamlit interactive dashboard



\## Machine Learning Models Used

\- Linear Regression

\- Ridge Regression

\- Decision Tree

\- Random Forest

\- Gradient Boosting

\- XGBoost

\- Deep Learning



Best Model: Gradient Boosting  

R² Score: 0.988



\## Tech Stack

\- Python

\- Scikit-learn

\- XGBoost

\- Streamlit

\- Pandas



\## Run Locally



Install dependencies:



```

pip install -r requirements.txt

```



Run the app:



```

streamlit run app.py

```



\## Demo



This system simulates pricing engines used by companies like Amazon and Uber.
